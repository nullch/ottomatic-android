# Русские глифы для шрифта Otto Matic

Готовые файлы шрифта с кириллицей в стиле оригинала (белые буквы, синее свечение; во втором атласе красное).

## Что внутри
- Готовые файлы `font.sfl`, `font1.tga`, `font2.tga` лежат в `game-data-overlay/System/` (в корне репозитория). `setup.sh` / `setup.bat` копируют их поверх `Data/System/` оригинальной игры.
- В `game/src/3D/TextMesh.c` константа `ATLAS_HEIGHT` уже равна 2048 (атлас стал 1024x2048). БЕЗ ЭТОГО текст будет мусором: размер текстуры берётся из констант, а не из файла.
- `docs/font-preview.png` — как выглядит текст (латиница из оригинала для сравнения, затем кириллица синим и красным).
- `gen_ru_font.py` — генератор (читает ОРИГИНАЛЬНЫЕ файлы, не наши), `verify_font.py` — проверка. Оба лежат в этой папке.

## Как установить вручную
Если не используете `setup.sh`: скопируйте три файла из `game-data-overlay/System/` в `Data/System/`. Язык `LANGUAGE_RUSSIAN` определён в `localization.h` и `Localization.c`; текстовые строки читаются из `Data/System/strings.csv` (колонка по номеру языка).

## Что сделано (и что нет)
- Верхние 1024 строк атласов и 175 исходных глифов не тронуты (проверяется `verify_font.py`).
- Добавлено 67 глифов: А-Я, а-я, Ё, ё, № (U+0410-044F, U+0401, U+0451, U+2116). Украинские/белорусские буквы не добавлены.
- Формат файлов тот же, что у оригинала: TGA type 9 (RLE, палитра 24 бита, начало сверху-слева). Игровой `ReadTGA` такое читает.
- Метрики подогнаны под оригинал: высота заглавных 31 px, строчных 23 px, базовая линия на 52, поля свечения 20 px.
- НЕ проверено на устройстве. Проверено только скриптом (разбор SFL как в `ParseSFL`, границы и пересечения глифов, совпадение исходной области) и по превью.

## Перегенерация
    python3 gen_ru_font.py <оригинальный Data/System> <куда писать> <LiberationSans-BoldItalic.ttf>
    python3 verify_font.py <куда писали> <оригинальный Data/System> preview.png
